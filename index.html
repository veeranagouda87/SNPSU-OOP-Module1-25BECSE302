1. Features of Java

Java (Sun Microsystems, 1995; now Oracle; James Gosling is the “father of Java”) was first named Oak. Its key promise: Write Once, Run Anywhere (WORA).

Syntax is based on C/C++, but pointers and operator overloading were removed.
Everything is modelled with classes and objects. Primitives (int, etc.) stay non-objects for speed.
The compiler emits architecture-neutral bytecode; any machine with a JVM can run it (architecture neutral, portable, interpreted).
Strong compile-time type checking, automatic garbage collection, and object-oriented exception handling.
No explicit pointers, and programs run inside the JVM sandbox.
One program can do many tasks at once by sharing the same memory between threads.
The JIT compiler translates hot bytecode into native machine code. Also: distributed (TCP/IP support) and dynamic (run-time type information).

4. Introduction to OOP

POP (C): functions and data are separate, top-down design. OOP (Java): data and methods are bundled in objects.

Binds code and data together and protects them from outside misuse. The class is the unit of encapsulation (instance variables + methods).
One class acquires the properties of another (child inherits from parent), supporting hierarchical classification and reuse.
“One interface, many forms”: the same method name behaves differently depending on the object or arguments.
Show only essential features, hide the details – like a TV remote hides the electronics.

Class, object, constructors, static, this

class Student {
    String name; int age;
    static int count = 0;
    Student() { this("Unknown", 0); }            // default, chains
    Student(String name, int age) {              // parameterized
        this.name = name; this.age = age; count++;
    }
    Student(Student s) { this(s.name, s.age); }  // copy
    void show() { System.out.println(name + " " + age); }
    public static void main(String[] a) {
        Student s1 = new Student("Asha", 21);
        Student s2 = new Student();
        s1.show();
        System.out.println("Students created: " + Student.count);
    }
}
